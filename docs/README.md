## This folder contains the initial requirements and design artifacts for TutorCircle, a proposed peer-tutoring and group-study web application for AUBH students.

### Documentation Structure

- **requirements/** — Preliminary user stories, functional requirements, and non-functional requirements.
- **wireframes/** — Initial user-interface wireframes and design references.
- **diagrams/** — High-level architecture and UML diagrams.
- **agile/** — Sprint planning, meeting records, and other Agile documentation when approved for sharing.

These artifacts describe the project's planned functionality and initial design **(not a completed implementation)**.

Documents will be added and updated as they are reviewed by the team.

# TutorCircle — Preliminary User Stories

TutorCircle is a proposed web-based peer-tutoring and group-study platform for students at the American University of Bahrain (AUBH).

The following preliminary user stories describe the main features of TutorCircle from the perspectives of the three main user roles: students, tutors, and administrators.

## Student User Stories

### US-01: Search for Tutors

As a student, I want to search for tutors by course so that I can find academic help for a specific subject.

### US-02: View Tutor Profiles

As a student, I want to view tutor profiles so that I can learn about their subjects, experience, and availability before choosing a tutor.

### US-03: Check Tutor Availability

As a student, I want to check when tutors are available so that I can find a suitable time for tutoring.

### US-04: Join Tutoring Groups

As a student, I want to browse and join tutoring groups so that I can study with other students who need help in the same course.

### US-05: Submit Support Tickets

As a student, I want to submit a support ticket so that I can report problems or ask for help when using TutorCircle.

## Tutor User Stories

### US-06: Create Tutor Profile

As a tutor, I want to create a profile with my subjects and experience so that students can understand what I can help them with.

### US-07: Set Availability

As a tutor, I want to set my available days and times so that students can see when I am available for tutoring sessions.

### US-08: Manage Tutoring Requests

As a tutor, I want to view and manage tutoring requests so that I can organize my tutoring sessions.

### US-09: Manage Tutoring Groups

As a tutor, I want to manage my tutoring groups and their members so that I can keep sessions organized.

## Admin User Stories

### US-10: Verify and Approve Tutor Applications

As an admin, I want to review and approve tutor applications so that students can find approved peer tutors.

### US-11: Manage User Accounts

As an admin, I want to manage user accounts so that I can maintain appropriate access to the platform.

### US-12: Manage Tutoring Groups

As an admin, I want to manage tutoring groups so that I can address problems and keep the platform organized.

### US-13: Review Reports and Issues

As an admin, I want to review reported problems so that I can respond to inappropriate activity or other issues on the platform.

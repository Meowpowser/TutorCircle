# TutorCircle - Sprint 2 Documentation

This folder contains the Sprint 2 documentation for **TutorCircle**, developed by **Group 9** for SWEN 360 (Software Design and Engineering) at the American University of Bahrain (AUBH).

Sprint 2 focuses on architecture selection, detailed system design, ethical planning, and continued Agile project management.

## Folder Structure

| Folder | Description |
|---|---|
| `architecture/` | Architecture analysis report, architectural comparisons, decision matrix, and design patterns. |
| `diagrams/` | Detailed UML class, sequence, and component diagrams. |
| `wireframes/` | Student, Tutor, and Admin interface designs and user flows. |
| `agile/` | Sprint planning, meeting records, stand-ups, Kanban evidence, burndown chart, impediment log, and velocity analysis. |
| `ethics/` | Ethical design statement addressing privacy, fairness, safety, and design trade-offs. |
| `detailed-design/` | Integrated Detailed Design Document explaining the system architecture, UML diagrams, and UI/UX decisions. |

# Wireframes

This folder contains TutorCircle's initial user-interface wireframes and links to design prototypes.

## Interactive Figma Prototype

**[TutorCircle Prototype - Figma](https://www.figma.com/design/FjqG11HLWe2Zk7bZJcZhwA/TutorCircle---Prototype?node-id=0-1&t=fuW5wrincAOo2cOY-1)**

The Figma prototype includes 11 desktop screens covering the Student, Tutor, and Admin interfaces, along with an application confirmation overlay. It demonstrates the main navigation flows and interactions of TutorCircle.

## Design Details

- **Design tool:** Figma
- **Original wireframes:** Canva
- **Frame size:** 1440 × 1024 px
- **Font:** Inter
- **Color scheme:** Slate and Sage
- **Primary colors:** `#304B5A` (slate) and `#356C63` (sage)

## Contributions

The initial wireframes were designed by Maryam. Helena translated these wireframes into Figma, applied the agreed color scheme and typography, and connected the main screens to create the interactive prototype.

# TutorCircle

**SWEN 360: Software Design & Engineering - Group 9**

TutorCircle is a peer tutoring and group study platform designed for students at the American University of Bahrain (AUBH).

The idea is to provide a place where students can find peer tutors for their courses, check available tutoring sessions, and join study groups with other students.

## Project Overview

TutorCircle focuses on making academic support easier to find within the university. Students can look for help with specific courses, while tutors can share their availability and organize tutoring sessions.

The platform is planned around three main user roles:

- **Student:** Searches for tutors, views tutor profiles, and joins tutoring groups.
- **Tutor:** Creates a tutor profile, sets availability, and manages tutoring requests.
- **Admin:** Reviews tutor applications and manages users, groups, and reported issues.

The project is currently in the first phase, **planning and design stage**. The team is working on the requirements, diagrams, wireframes, and project documentation before moving into implementation.

## UML and System Diagrams

UML diagrams are being prepared to describe the main interactions, information, and processes in TutorCircle.

The initial design includes three types of diagrams:
- **Use-case diagram:** Shows the actions available to Students, Tutors, and Admins.
- **Information view (class diagram):** Represents important system elements such as users, courses, tutoring groups, and requests, along with their relationships.
- **Behavior view:** Describes how a selected process changes over time, such as the status of a tutoring request.

These diagrams will be used to support the initial system design and clarify how different parts of TutorCircle relate to each other.

## Website Layout and Wireframes

The website wireframes will be done on Canva to show the planned layout of TutorCircle's main pages before development begins. The design will focus on how students, tutors, and admins access the features available to their roles.

Some of the main screens being considered are:
- Login and user profile pages
- Student homepage with tutoring groups and course filters
- Group details page showing members, capacity, location, and meeting time
- Tutor dashboard for availability and tutoring requests
- Admin dashboard for tutor approvals and user management

The wireframes will help organize the navigation and placement of important features across the website.

## Initial Requirements

The functional and non-functional requirements for TutorCircle have been drafted as part of the first phase of the project.

The functional requirements cover the main activities of the platform, such as:
- Logging in using an AUBH account
- Creating student and tutor profiles
- Viewing and filtering tutoring groups
- Joining groups based on available capacity
- Using group chats to coordinate study sessions
- Managing tutoring requests and tutor approvals
- Sending support tickets
  
The non-functional requirements focus on account verification, user permissions, privacy of group chats, usability, and accessibility across laptops and mobile devices. The requirements will be reviewed and used as a reference for the system design.

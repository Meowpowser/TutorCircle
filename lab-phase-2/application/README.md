# TutorCircle — SWEN 360L Phase 2

This folder contains the TutorCircle web application developed for SWEN 360L Phase 2 at the American University of Bahrain (AUBH).

## Project Overview

TutorCircle is a peer tutoring and collaborative study platform designed for AUBH students. The application supports three main user roles: Student, Tutor, and Admin.

## Implementation

The application was developed based on the Phase 1 Figma prototype and its documented functionalities. The high-fidelity designs were used as references for the application's interface.

The application source code and supporting files are stored in this folder.

## Running the Application

Instructions for running the application and any required demo login credentials will be added after the final implementation is verified.

## Testing

The team will test the implemented functionalities and report any issues identified during testing. The final results and any unresolved limitations will be documented in the Lab Phase 2 report.
